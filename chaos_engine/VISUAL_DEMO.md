# CHAOS ENGINE — visual demo milestone

The first animated 32-second visual documentary proof-of-concept is generated by a Python + Pillow frame renderer, FFmpeg video encoder, and optional eSpeak test narration.

Run with Python 3, Pillow, FFmpeg, and optionally eSpeak:

```bash
python chaos_engine/visual_demo.py
```

Output: `/mnt/data/chaos_visual_demo.mp4` (adjust OUT in script for other environments).

**Disclosure:** The interface graphics, counters, timestamps and comments are fictional illustrative assets, not evidence of an actual scam. No third-party video footage is used. The voice is an eSpeak placeholder, not Kokoro. This is not a finished automated documentary production pipeline.

Next milestones: user-provided licensed video assets, script-aligned shot selection, Kokoro voice, and reproducible quality checks.
